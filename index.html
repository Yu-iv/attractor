Rössler Chaos

Monochrome 3D

A continuous 3D chaotic dynamical system tracing complex topological orbits via Runge-Kutta 4th Order Integration (RK4).

dx/dt = -y - z dy/dt = x + a·y dz/dt = b + z(x - c)
